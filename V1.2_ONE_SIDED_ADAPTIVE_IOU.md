# SO-DETR V1.2 — One-Sided Scale-Adaptive Expanded-IoU

V1.2 is a follow-up to the V1.1 scale-adaptive Expanded-IoU experiment. It keeps all historical V1.1 modes and results unchanged, and introduces a new controlled experiment named **Q1P**.

The motivation comes from the seed-0 V1.1 result: Q1 slightly improved `APs` but reduced `APm`, while total AP stayed close to Q0. This suggests that scale adaptation may help small targets, but the original V1.1 curve also changes supervision for medium and large targets.

## Why V1.2 exists

The published SO-DETR behavior uses a fixed Expanded-IoU ratio:

```text
ratio = 1.25
```

V1.1 Q1 uses:

```text
ratio = clamp(1 + alpha * exp(-normalized_area / tau), min_ratio, max_ratio)
```

with the defaults:

```text
alpha = 0.5
tau = 0.01
min_ratio = 1.0
max_ratio = 1.5
```

Because the adaptive curve approaches `1.0` as object area increases, Q1 does two things at once:

1. it gives very small targets a ratio larger than `1.25`;
2. it gives sufficiently large targets a ratio smaller than `1.25`.

With the default parameters, the adaptive curve crosses the baseline `1.25` at:

```text
a = tau * ln(alpha / (1.25 - 1.0))
  = 0.01 * ln(2)
  ≈ 0.00693
```

For a 640×640 image, that corresponds to an equal-area square of roughly 53×53 pixels. Targets smaller than this receive `ratio > 1.25`; larger targets receive `ratio < 1.25` in V1.1 Q1.

The seed-0 measurements are consistent with this possible trade-off:

| Run | AP | AP50 | AP75 | APs | APm | APl |
|---|---:|---:|---:|---:|---:|---:|
| Q0 | 29.13 | 47.86 | 29.78 | 20.58 | 39.99 | 42.23 |
| Q1 | 28.90 | 48.16 | 29.36 | 21.05 | 39.06 | 45.73 |

These are still single-seed measurements and are not sufficient for a statistical conclusion.

## Q1P design

Q1P makes the adaptation **one-sided**:

```text
ratio = clamp(
    1 + alpha * exp(-normalized_area / tau),
    fixed_ratio,
    max_ratio,
)
```

Default values:

| Parameter | Value |
|---|---:|
| `fixed_ratio` | 1.25 |
| `alpha` | 0.5 |
| `tau` | 0.01 |
| lower bound | `fixed_ratio` = 1.25 |
| `max_ratio` | 1.5 |

This means:

- very small targets can still receive up to `1.5`;
- targets above the crossover fall back to exactly the original `1.25` behavior;
- the regression branch remains fixed at `1.25`;
- only query-quality supervision changes;
- inference structure, parameters, FLOPs, and latency remain unchanged.

The implementation deliberately reuses the existing V1.1 ratio generator and sets `expanded_iou_min_ratio = expanded_iou_fixed_ratio`. No historical V1.1 mode is redefined.

## Experiment naming

| ID | Quality target | Regression | Purpose |
|---|---|---|---|
| Q0 | fixed 1.25 | fixed 1.25 | historical baseline |
| Q1 | legacy adaptive `[1.0, 1.5]` | fixed 1.25 | V1.1 adaptive-quality |
| Q1P | one-sided adaptive `[1.25, 1.5]` | fixed 1.25 | V1.2 small-target-only tolerance test |
| Q2 | fixed 1.25 | legacy adaptive `[1.0, 1.5]` | regression diagnosis |
| Q3 | legacy adaptive `[1.0, 1.5]` | legacy adaptive `[1.0, 1.5]` | full V1.1 adaptation |

## Recommended run

Use the dedicated launcher:

```bash
python run_sodetr_v1_2_one_sided.py \
  --model r18 \
  --data configs/visdrone-local.yaml \
  --device 0,1 \
  --epochs 400 \
  --patience 40 \
  --batch 8 \
  --imgsz 640 \
  --workers 8 \
  --seed 0 \
  --close-mosaic 0 \
  --mixup 0.2 \
  --lrf 1.0
```

Equivalent direct command:

```bash
python train_sodetr_visdrone.py \
  --model r18 \
  --data configs/visdrone-local.yaml \
  --device 0,1 \
  --seed 0 \
  --expanded-iou-mode adaptive-quality \
  --expanded-iou-fixed-ratio 1.25 \
  --expanded-iou-alpha 0.5 \
  --expanded-iou-tau 0.01 \
  --expanded-iou-min-ratio 1.25 \
  --expanded-iou-max-ratio 1.5
```

The launcher names the run as:

```text
sodetr-v1.2-r18-q1p-one-sided-quality-seed0
```

and records an explicit experiment description so that the reporting pipeline does not confuse Q1P with historical Q1.

## Recommended next experimental sequence

Finish the existing V1.1 matrix first:

```text
Q3 seed0
```

Then verify whether the Q0/Q1 difference is stable across seeds:

```text
Q0 seed1
Q1 seed1
Q0 seed2
Q1 seed2
```

Q1P can be run at seed0 in parallel as a hypothesis test. If Q1P preserves the Q1 small-object gain while recovering medium-object AP and improving total AP, continue with Q1P seeds 1 and 2.

The primary comparison should report:

```text
AP, AP50, AP75
APs, APm, APl
per-class AP
mean ± std over seeds
```

Do not reinterpret old Q1 runs as Q1P. Q1 and Q1P have different ratio lower bounds and must remain separate experiments in reports and paper tables.
