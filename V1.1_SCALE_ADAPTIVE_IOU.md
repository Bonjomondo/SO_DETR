# SO-DETR V1.1 — Scale-Adaptive Expanded-IoU

V1.1 is the first method change after the clean V1.0 baseline. It targets one specific SO-DETR limitation: every target currently uses the same Expanded-IoU ratio of `1.25`, regardless of object scale.

## Design decision

For a normalized ground-truth area \(a_i = w_i h_i\), V1.1 computes:

\[
r_i = \operatorname{clip}
\left(
1 + \alpha \exp\left(-\frac{a_i}{\tau}\right),
r_{\min},
r_{\max}
\right)
\]

Default values:

| Parameter | Value | Meaning |
|---|---:|---|
| `alpha` | 0.5 | Maximum additive expansion before clamping |
| `tau` | 0.01 | Decay scale in normalized image area |
| `min_ratio` | 1.0 | Large-target lower bound |
| `max_ratio` | 1.5 | Very-small-target upper bound |
| `fixed_ratio` | 1.25 | Published SO-DETR behavior for non-adaptive branches |

The ratio is derived from the matched ground-truth box, not the predicted box. It is therefore stable and does not create a trainable shortcut through the ratio function.

## Recommended experiment

The main V1.1 setting is:

```text
expanded_iou_mode = adaptive-quality
```

Only the IoU target used by the RT-DETR Varifocal query-quality supervision becomes scale-adaptive. The final box regression branch remains at the published SO-DETR fixed ratio of `1.25`.

This boundary is intentional:

- query selection benefits from extra tolerance for tiny targets;
- regression remains unchanged so V1.1 can be attributed to query-quality calibration;
- the inference graph, parameter count, FLOPs, and latency are unchanged;
- the legacy response-distillation loss remains unchanged.

## Important behavior of the V1.1 curve

The original V1.1 adaptive curve is not one-sided around the published `1.25` baseline. With the default parameters it increases the ratio above `1.25` for sufficiently small targets, but decreases it below `1.25` for sufficiently large targets.

The crossover is obtained from:

\[
1 + 0.5\exp(-a/0.01) = 1.25,
\]

which gives approximately:

```text
a = 0.00693
```

For a 640×640 image this is equivalent to an equal-area square of roughly 53×53 pixels. Therefore historical Q1 simultaneously tests two effects:

- extra tolerance for targets below the crossover;
- stricter-than-baseline Expanded-IoU geometry for targets above the crossover.

This distinction matters when interpreting the seed-0 result, because Q1 improved `APs` while reducing `APm` relative to Q0. A follow-up experiment that isolates only the first effect is documented in [V1.2_ONE_SIDED_ADAPTIVE_IOU.md](V1.2_ONE_SIDED_ADAPTIVE_IOU.md).

## Implementation boundary

V1.1 changes:

- `ultralytics/utils/metrics.py`: per-target ratio generation and tensor-ratio support;
- `ultralytics/models/utils/loss.py`: configurable quality/regression application;
- `ultralytics/nn/tasks.py`: training arguments passed into the RT-DETR criterion;
- `ultralytics/utils/dist.py`: original CLI arguments forwarded to custom DDP entry points;
- `ultralytics/cfg/default.yaml`: DDP- and resume-visible settings;
- `train_sodetr_visdrone.py`: reproducible V1.1 command-line interface;
- `run_sodetr_v1_1_ablation.py`: sequential Q0-Q3 runner.

V1.1 does not change:

- backbone, DDF, SPDConv, hybrid encoder, decoder, or query count;
- Neighborhood Attention;
- teacher/student distillation;
- inference or export code.

## Evaluation

Compare Q1-Q3 to Q0 using the same seed and training protocol. Record at least:

```text
AP50-95, AP50, AP75
AP_small, AP_medium, AP_large
precision, recall, per-class AP
parameters, GFLOPs, latency, peak memory
```

The main check is not only whether `AP_small` rises. V1.1 is successful when small-object performance improves while `AP_large` stops declining or remains statistically stable.

Run seed 0 first. Only after selecting the best one or two modes, run seeds 1 and 2.

- Single seed-0 runs. The reporting pipeline does not compute delta-to-baseline here,
  because Q0 predates structured telemetry and the runs are not yet verified as

## V1.2 follow-up: Q1P

Do **not** reinterpret historical Q1 results. V1.2 adds a separate experiment, Q1P, whose adaptive quality ratio is lower-bounded by the published fixed ratio:

```text
ratio = clamp(1 + alpha * exp(-area / tau), fixed_ratio, max_ratio)
```

With defaults this becomes `[1.25, 1.5]` instead of V1.1 Q1's `[1.0, 1.5]`. Regression stays fixed at `1.25`.

Run it with:

```bash
python run_sodetr_v1_2_one_sided.py \
  --model r18 \
  --data configs/visdrone-local.yaml \
  --device 0,1 \
  --seed 0
```

Full rationale and the recommended multi-seed sequence are in [V1.2_ONE_SIDED_ADAPTIVE_IOU.md](V1.2_ONE_SIDED_ADAPTIVE_IOU.md).

Machine-generated tables, per-class AP and plots: [`reports/experiments.md`](reports/experiments.md).
